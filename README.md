# Avaliação de uma extensão de acessibilidade para o Visual Studio Code

## Apresentação

Esta atividade faz parte de uma pesquisa acadêmica realizada no Trabalho de Conclusão de Curso de Ciência da Computação da UERJ.

O objetivo é avaliar uma extensão desenvolvida para o Visual Studio Code que auxilia na identificação de possíveis problemas de acessibilidade em código HTML.

A extensão analisa o código e apresenta diagnósticos na aba Problems do Visual Studio Code. Em alguns casos, também são disponibilizadas sugestões automáticas de correção por meio de Quick Fixes.

O objetivo desta atividade é avaliar a extensão, e não o conhecimento ou o desempenho individual do participante.

## Antes de continuar

Antes de realizar a atividade, você deve:

1. ler o Termo de Consentimento Livre e Esclarecido;

## Requisitos

Para realizar a atividade, será necessário:

- um computador com o [Visual Studio Code](https://code.visualstudio.com/download) instalado;
- conhecimento básico de HTML;
- acesso à internet para baixar os materiais;
- permissão para instalar uma extensão no formato `.vsix`.

## Etapas da atividade

Você deverá:

1. baixar a extensão;
2. instalar a extensão no Visual Studio Code;
3. baixar o arquivo HTML da atividade;
4. abrir o arquivo no Visual Studio Code;
5. consultar os diagnósticos apresentados na aba Problems;
6. realizar as correções que considerar necessárias;
7. utilizar os Quick Fixes quando considerar apropriado;
8. responder ao questionário de avaliação pós-uso.
